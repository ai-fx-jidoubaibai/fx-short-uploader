# Privacy Policy (fx-short-uploader)

Last updated: 2026-11-10

fx-short-uploader is a personal tool used only by the owner of the YouTube channel "AIと作るFX自動売買". It uses YouTube API Services.

## What data it uses
- It uses Google OAuth to get permission to upload videos to the owner's own YouTube channel.
- It sends the video file, title, description, tags, thumbnail and publish time to YouTube.
- It does not collect data from any other users.

## How data is stored
- The OAuth token is stored only on the owner's PC.
- No data is sold or shared with third parties.

## How to revoke access
Access can be removed at any time from Google security settings:
https://security.google.com/settings/security/permissions
After access is removed, the stored token is deleted.
