# fx-short-uploader

fx-short-uploader is a personal tool used only by the owner of the YouTube channel "AIと作るFX自動売買" (@ai_fx_jidoubaibai).

It runs on the owner's own PC and uploads the channel's daily short videos to YouTube using the YouTube Data API.

- It is not offered to other users.
- It only uploads videos to the owner's own channel.
